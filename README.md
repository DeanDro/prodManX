# prodManX

**prodManX** is a high-performance tool for product managers, product owners and scrum masters designed to enhance productivity, simplify tasks, and help stakeholders identify bottlenecks in processes.

## Product Description

## Tech Stack 

This project uses a modern, "Velocity-First" stack designed for 2026 standards:

* **Framework:** [Next.js 15+](https://nextjs.org/) (App Router)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Components:** [shadcn/ui](https://ui.shadcn.com/) (Built on Radix UI)
* **Database & Auth:** [Supabase](https://supabase.com/) (PostgreSQL + SSR Auth)
* **Icons:** [Lucide React](https://lucide.dev/)

---

## ✨ Core Features

- **Visual Launch Mapping:** Drag-and-drop interfaces for planning launch phases.
- **Cross-Platform Accessibility:** Optimized for Desktop, Tablet, and Mobile browsers.
- **Real-time Sync:** Powered by Supabase to ensure team members see updates instantly.
- **Secure Authentication:** Server-side rendered (SSR) auth for enterprise-grade security.
- **Operational Checklists:** Pre-configured templates for go-to-market strategies.
